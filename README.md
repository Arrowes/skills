# Skills 与自动化脚本

个人 Codex Skill 和 Windows 自动化脚本仓库。仓库只保存可复用代码与说明，不保存飞书 App Secret、访问令牌、用户 ID 或会话 ID。

## 目录

| 目录 | 作用 |
| --- | --- |
| [`lark-scripts/`](./lark-scripts/) | 飞书 CLI、Codex bridge、额度卡和关机卡的安装与自动化。 |
| [`codex-scripts/`](./codex-scripts/) | Codex 本机运行辅助脚本，目前包含代理与网络守护。 |
| [`interview-review-coach/`](./interview-review-coach/) | 技术面试录音、转录和笔记复盘 Skill。 |

## 外部 Skill 索引

| 类别 | Skill |
| --- | --- |
| Codex 系统 | `imagegen`、`openai-docs`、`plugin-creator`、`skill-creator`、`skill-installer` |
| 搜索 | `anysearch`、`find-skills` |
| 开发 | `ponytail`、`superpowers` |
| 求职 | `job-hunter` |
| 视觉与视频 | `cinematic-director-frame`、`chatcut` |

外部 Skill 的实际版本和来源以各自安装目录为准。本仓库中的自动化脚本可直接复制到新机器，并按对应目录的 README 重建。
