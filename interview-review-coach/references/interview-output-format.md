# Interview Output Format

Use this format for full interview recaps.

```markdown
# 面试问答复盘：<公司或场次> <日期>

> 说明：本文基于 <音频/转录/笔记> 整理。对明显转写错误按上下文保守修正；无法确认的片段标注为“未完全听清”。
>
> 结构：每个问题包含“问题 / 我的回答 / 建议回答”。“我的回答”尽量如实记录现场表达；“建议回答”从专业面试官视角补全表达。

---

## 一、<公司或面试轮次>

### 1. <问题主题>

**问题**

<面试官原始问题，保留必要的你/你们。>

**我的回答**

<直接记录用户实际回答。不要写“回答中提到/候选人表示/你说”。>

**建议回答**

<更完整、更有结构的面试回答。只使用来源中可支持的经历。>

---

## 二、整体表现总结

### 优势

- <优势 1>
- <优势 2>

### 主要问题

- <问题 1>
- <问题 2>

## 三、知识点汇总、补充与扩展

### 1. <知识点>

**来自问题**

<对应问题>

**必须掌握**

<最低掌握内容>

**容易追问**

- <追问 1>
- <追问 2>

**优秀回答要点**

- <要点 1>
- <要点 2>

**容易踩坑**

- <踩坑点>

**复习优先级**

High / Medium / Low

## 四、下次面试复习优先级

1. <最高优先级>
2. <第二优先级>
3. <第三优先级>
```

## Rewrite Rules

For `我的回答`, transform only the narrator perspective, not the factual content.

| Bad | Good |
|---|---|
| 回答中提到主要负责泊车感知 | 我主要负责泊车感知 |
| 候选人表示没有参与超声波融合 | 我负责的模块没有融合超声波 |
| 你说项目里有两套算法 | 项目里有两套算法 |
| 现场自我介绍中提到发表过两篇 SCI | 研究生期间发表过两篇 SCI |

Question headings can be normalized for readability, but do not change the meaning of the original question.
